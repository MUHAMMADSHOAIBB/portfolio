#01
Python PyQt5 Neuroimaging M.Sc. Thesis

SCAT — Single Cell Annotation Toolbox

A Python/PyQt5 desktop application integrating AHBA-derived cell type spatial maps with disease-specific functional connectivity networks across 11 psychiatric & neurological disorders. Features a 3D FC Network Viewer, Cell Type Enrichment Analysis with spatial permutation testing (up to 10,000 permutations), and a 3D Results Viewer with HTML export. Applied to Parkinson's disease data identifying endothelial cell enrichment in the lingual gyrus.
